1. Run Commend Create Project 
>django-admin startproject [nameproject]

or

>django -m django startproject [nameproject]

2. Run Commend Create App

>py .\manage.py startapp [nameapp]

3. Run Commend Create database

>python manage.py makemigrations

4. Run Commend Create Table

>python manage.py migrate

5. Create Superuser

>py. manage.py createsuperuser
